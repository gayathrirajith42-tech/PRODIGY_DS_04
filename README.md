# PRODIGY_DS_04

## Social Media Sentiment Analysis

## Project Overview
This project focuses on analyzing and visualizing sentiment patterns in Twitter data to understand public opinion and attitudes toward different topics and brands. The analysis was performed using Python and data visualization techniques to identify Positive, Negative, Neutral, and Irrelevant sentiments.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The project uses the following datasets:
- `twitter_training.csv`
- `twitter_validation.csv`

These datasets contain tweets classified into four sentiment categories:
- Positive
- Negative
- Neutral
- Irrelevant

## Features
- Sentiment Distribution Analysis
- Bar Chart Visualization
- Pie Chart Visualization
- Training vs Validation Comparison
- Topic-wise Analysis

## Analysis Performed
1. Loaded and explored the Twitter sentiment datasets.
2. Analyzed the distribution of sentiment categories.
3. Created bar charts to visualize sentiment frequencies.
4. Generated pie charts to represent sentiment percentages.
5. Compared sentiment patterns between training and validation datasets.
6. Examined sentiment trends across different topics and brands.

## Results
- Negative sentiment was the most common category in the training dataset.
- Positive sentiment was the second most frequent category.
- The validation dataset showed a relatively balanced sentiment distribution.
- Visualizations provided clear insights into overall sentiment trends and user opinions.

## Conclusion
This project successfully analyzed sentiment patterns in Twitter data and visualized public opinion using various charts and graphs. The results provide valuable insights into user opinions, engagement trends, and sentiment distribution across different topics and brands.
